### ▸ ~/selected-work

**value prospecting** — a civic web platform built for a real client by a team of six over four Scrum sprints. I built the core of the React + TypeScript frontend: the global infographic, the personalised dashboard and the multi-step impact assessment. It runs on FastAPI + PostgreSQL with GitLab CI/CD.
`React` `TypeScript` `Tailwind` `FastAPI` `PostgreSQL`

**concurrent disk driver** — a multithreaded disk driver in C. Application threads queue their reads and writes through bounded buffers and the driver serves them first come, first served, using POSIX threads, mutexes and condition variables. No dynamic memory allocation anywhere.
`C` `pthreads` `concurrency`

**intern onboarding platform** — the site I wanted in my first week at Batelco. A guide for new interns, plus an anonymous board where people leave advice for whoever comes next. Supabase/PostgreSQL behind it, live on Vercel.
`React` `Vite` `Tailwind` `Supabase` `Vercel`

**cryptographic attack programs** — two attacks in Java that break an 8-rotor cipher machine, one with known plaintext and one with ciphertext only, using dictionary search and English letter frequencies. I also worked out the shortest ciphertext you need to decrypt it unambiguously, in theory and then by experiment.
`Java` `cryptanalysis`

**concurrent strace log analyser** — a multithreaded C++ tool that goes through millions of strace log lines and tells you how often each syscall was called and how often it failed.
`C++` `multithreading`

**ai-driven trading system** — a trading system that reads live financial news and changes its strategy based on the sentiment. Built in a team of five at Hack the Burgh XII.
`Python` `sentiment analysis` `APIs`
